│   describe <resource> <name>            Detailed resource description        │

│   delete pod <name>                     Force delete a pod                   │
│   # Deployments                                                              │

│   --replicas=N                                                               │

│   # Apply / Delete                                                           │

│   --sort-by=.lastTimestamp                                                   │
│   # Context & Config                                                         │

│   # Nodes                                                                    │
